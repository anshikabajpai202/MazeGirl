# 🎮 MazeGirl

MazeGirl is a fun and interactive maze adventure game developed using **Python** and **Pygame**.  
The player must navigate through maze challenges, avoid obstacles, and successfully reach the destination to complete each level.

The game includes multiple difficulty levels with engaging gameplay and visually appealing maze layouts.

---

## ✨ Features

-  Easy and hard maze levels
-  Smooth keyboard controls
-  Challenging obstacle navigation
-  Level completion screens
-  Interactive gameplay experience
-  Built using Python and Pygame

---

##  Technologies Used

- Python
- Pygame

##  Installation & Run

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/anshikabajpai202/MazeGirl.git
```

### 2️⃣ Navigate to Project Folder

```bash
cd MazeGirl
```

### 3️⃣ Install Required Library

```bash
pip install pygame
```

### 4️⃣ Run the Game

```bash
python game.py
```
